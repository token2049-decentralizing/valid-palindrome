### Problem: Valid Palindrome

Given a string `s`, determine whether it is a palindrome.

A palindrome is a string that reads the same forward and backward. **Ignore all non-alphanumeric characters and ignore case differences.**

### Sample Input / Output

**Example 1**

```text
Input: s = "A man, a plan, a canal: Panama"
Output: true
```

**Example 2**

```text
Input: s = "race a car"
Output: false
```

**Example 3**

```text
Input: s = " "
Output: true
```

**Constraints**

```text
1 <= s.length <= 2 * 10^5
s consists only of printable ASCII characters.
```
